# CLI Help - Updated for Phase 4

## screen command (with research stage)

```
Usage: python -m multibagger.cli.main screen [OPTIONS] STAGE

Run screening pipeline stages

╭─ Arguments ──────────────────────────────────────────────────────────────╮
│ *    stage      TEXT  Stage: fast, quality, business, redflags,         │
│                       research, or all                                   │
│                       [required]                                         │
╰──────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────╮
│ --as-of           TEXT  Run as-of YYYY-MM (defaults to current month)   │
│ --output-dir  -o  TEXT  Output directory [default: snapshots]           │
│ --help                  Show this message and exit.                     │
╰──────────────────────────────────────────────────────────────────────────╯
```

## Examples

```bash
# Run individual stages
multibagger screen fast --as-of 2025-11
multibagger screen quality --as-of 2025-11
multibagger screen business --as-of 2025-11
multibagger screen redflags --as-of 2025-11
multibagger screen research --as-of 2025-11

# Run full pipeline
multibagger screen all --as-of 2025-11

# Custom output directory
multibagger screen research --as-of 2025-11 --output-dir custom_snapshots
```
